# YOLOv11 Background Replacement

Замена фона в реальном времени с использованием YOLO-сегментации. Программа выделяет человека с веб-камеры и заменяет фон на выбранное изображение.

## 🚀 Возможности

- **Сегментация в реальном времени**: Использует YOLO для точного выделения человека
- **Замена фона**: Настраиваемый фон (изображение или чёрный)
- **Сглаживание масок**: Временная стабилизация для плавного результата
- **Морфологические операции**: Улучшение качества маски
- **Отображение FPS**: Мониторинг производительности

## 🛠 Использование

### Базовый запуск:
```bash
python yolov11_seg.py
```

### Настройка параметров:

Измените параметры в функции `main()`:

```python
# Загрузка кастомной модели
model = load_model('your-model.pt')

# Использование кастомного фона
background = load_background('your-background.jpg')

# Настройка камеры (если несколько камер)
cap = initialize_camera(1)  # индекс камеры
```

### Параметры обработки в функции `process_frame()`:
- `conf_threshold=0.5` - порог уверенности детекции
- `mask_smoothing_alpha=0.7` - коэффициент сглаживания масок (0-1)

## 🎮 Управление

- **Q** - выход из программы
- Окна:
  - `Background Replacement` - финальный результат с заменённым фоном
  - `Human Mask` - визуализация маски сегментации (закомментировано)
